# 央视频TV (Yangshipin TV)

基于 [WebViewTvLive](https://github.com/hxh19950701/WebViewTvLive) 魔改的**单源极简电视直播 App**：只使用央视频官方网页 `https://www.yangshipin.cn/tv/home`，一个标签页看遍央视与全国卫视。

> Fork 自 [hxh19950701/WebViewTvLive](https://github.com/hxh19950701/WebViewTvLive)，感谢原作者开源。本 Fork 自 v2.4.0 起弃用腾讯 X5 内核，改用 Android 系统 WebView（Chromium）。

## 理念：映射点击

本应用不解析任何视频流，也不内置任何播放地址。它只做一件事：

```
你的选择(弹窗/遥控)  →  虚拟鼠标注入脚本  →  点击央视频页面上的对应按钮
         换台                  一次 JS click            频道按钮
         清晰度               一次 JS click            清晰度菜单项
```

画面布局由注入 CSS 控制: 隐藏网页头部/侧栏/节目单, 播放器铺满整屏。切台/切清晰度全程原生黑幕过渡，起播后揭幕，平滑无闪烁。

## 功能

- **单页播放**：全程只开一个标签页，换台不重新加载网页
- **沉浸式画面**：启动纯黑加载页，首帧就绪后揭开；打开即铺满整屏
- **频道**：央视 21 个（CCTV1 到 CCTV17 及 5+/4K/8K 衍生频道）+ 24 个卫视，剔除付费频道
- **换台面板**：左侧抽屉式，全部 / 央视 / 卫视 / ★收藏（固定底部），数字键编号、台标徽章、播放中标识
- **收藏**：长按频道加入/移出收藏；停留在收藏列表时，上下换台只在收藏内循环
- **数字键选台**：央视 1-21（CCTV1 到 CCTV17 及 5+/4K/8K 衍生频道），卫视 101-138
- **地区卫视优先**：自动识别所在省份，本省卫视排第一位
- **清晰度选择**：蓝光 1080P / 超清 720P / 高清 540P，默认蓝光；切换从原位置续播，不重播已看内容
- **清晰度跟随换台**：换台后自动恢复当前清晰度（页面切台会重置回蓝光，App 会切回你选的清晰度）
- **切台自愈**：换台后长时间无画面时自动重试（相当于"切其他台再切回来"），最多两次
- **点击分区**：单击屏幕左半边呼出频道列表，右半边呼出清晰度
- **设置面板**：上下按键方向反转开关、应用自动更新开关 + 手动检查更新
- **记忆播放**：每次打开自动回到上次退出的频道、清晰度与分类；启动直接切上次频道，省一次完整加载
- **自动更新**：开机自动检测新版本，弹窗提示一键下载安装（可在设置中关闭）
- **防误触遮罩**：触摸不透传网页，防止误触

## 操作方式

| 操作 | 手机/平板 | 电视/盒子 |
|---|---|---|
| 频道列表 | 单击屏幕**左半边** | 遥控器 OK / 确认键 |
| 清晰度 | 单击屏幕**右半边** | 遥控器 MENU 键 |
| 设置 | 清晰度面板底部"设置" | 清晰度面板底部"设置" |
| 选台 | 触摸点击频道 | 十字键导航 + OK 确认 |
| 收藏/取消收藏 | 长按频道 | 长按 OK 键 |
| 顺序换台 | 上滑=下一个，下滑=上一个（可在设置反转） | 下键=下一个，上键=上一个（可在设置反转） |
| 数字键选台 | 支持 | 支持 |
| 退出 | 返回键按两次 | 返回键按两次 |

## 获取 APK

从 [Releases](https://github.com/SteveKazer/WebViewTvLive/releases) 页面下载最新版 APK 直接安装。

也可自行构建：JDK 17 + Android SDK，`./gradlew assembleRelease`；推送到 main 分支或打 `v*` 标签时 GitHub Actions 自动构建发版。

## 设备要求

Android 5.0+，推荐 Android 11+；播放依赖系统 WebView 对现代网页的支持（建议保持 WebView 为较新版本）。

## 与原项目的差异

| | 原 WebViewTvLive | 本 Fork |
|---|---|---|
| 播放源 | 多源、播放列表可更新 | 仅央视频 tv/home |
| 内核 | 腾讯 X5 | Android 系统 WebView（Chromium） |
| 换台 | 重新加载整个网页 | 页内映射点击，一个标签页 |
| 清晰度 | 不可选 | 蓝光/超清/高清可选，跟随换台自动恢复 |
| 加载提示 | App 自绘黑屏进度 | 原生黑幕过渡 + 起播后揭幕 |
| 付费频道 | 未过滤 | 已剔除（限免/VIP），央视保留 CCTV1 到 CCTV17 及 5+/4K/8K 衍生频道 |
| 源码规模 | 41 个 Kotlin 文件 | 12 个 Kotlin 文件 |
