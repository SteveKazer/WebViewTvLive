# WebViewTvLive v2.4.7 / v2.4.8 版本撤回与修复存档

> 记录时间：2026-11-23
> 说明：应项目决定，v2.4.7 与 v2.4.8 两个版本已撤回（GitHub Release 与 tag 均删除，APK 不再提供），main 分支回退至 v2.4.6，后续从 v2.4.6 重建 v2.4.9 开发线。本文档按用户口述记录两个版本的修复内容，防止信息随版本撤回丢失；发布说明今后只列本次更新的差异与修复。

## v2.4.7 修复内容（口述记录）

1. **设置页上下键操作**：修复电视遥控器无法在设置面板内上下按键操作（设置上下键滚动）的问题。
2. **内核本地安装**：X5 内核支持本地文件导入安装；仓库根目录存档 32 位与 64 位内核安装包，在线镜像失效时可下载后本地导入。

## v2.4.8 修复内容（口述记录）

1. **频道列表左键返回**：修复频道列表按左键不返回对应分类、总跳到收藏的问题。
2. **设置页底色**：修复设置页开关在底色/聚焦行上颜色看不清的问题（开关配色重绘）。
3. **设置页进入内核下载操作**：设置页进入 X5 内核管理后，电视遥控可以操作内核下载安装。

## 处置说明

- v2.4.7 与 v2.4.8 的 Release、tag 已删除；v2.4.6 及更早版本全部保留。

- 被撤回版本的完整技术历史保留在归档分支 `feature/v2.4.9-playback-tuning`（commit d2b7299），可随时追溯。
